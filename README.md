# Website

My website and blog, live at [violetcaulfield.com](https://violetcaulfield.com).

Built with [Astro](https://astro.build) as a static site, and served from
[Cloudflare Workers static assets](https://developers.cloudflare.com/workers/static-assets/). The
blog and RSS feed work the same way as the [Jellify website](https://jellify.app/blog).
